# Sweet Flowers Deco Party — Project Bible

Documentación fuente de verdad del proyecto. Todo el equipo (humano o IA) parte de acá.

> **Regla de oro:** si el código contradice esta documentación, la documentación tiene prioridad hasta que se actualice de forma explícita y consensuada.

---

## Cómo usar esta documentación

1. **Claude Code / cualquier IA:** empezá por [`CLAUDE.md`](./CLAUDE.md) y después [`00_PROJECT_HANDOFF.md`](./00_PROJECT_HANDOFF.md).
2. **Dev senior que entra al proyecto:** leé el HANDOFF completo. En 20 minutos entendés el negocio, la visión, el nivel de calidad y la forma de trabajar sin preguntarle nada a nadie.
3. **Flor / negocio:** leé `01_BUSINESS`, `02_BRAND`, `03_TARGET_AUDIENCE` y `15_ROADMAP`.
